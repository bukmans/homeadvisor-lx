# 🏠 HomeAdvisor LX

**AI-Powered Luxembourg Home Purchase Advisor**

A full-stack demo application showcasing **AI + Automation** in a real-world use case. Built with React + Vite, powered by the Claude AI API (Anthropic), with automated email delivery via EmailJS.

---

## ✨ Features

| Feature | Technology | What It Demonstrates |
|---|---|---|
| Conversational AI intake | Claude API (claude-sonnet) | Natural language → structured data |
| Profile extraction | Claude API (JSON parsing) | AI reasoning over free text |
| Benefits calculation | Rules engine (JS) | Complex policy logic |
| AI narrative generation | Claude API | Personalised advisory writing |
| PDF report generation | Browser API (Blob/URL) | Client-side automation |
| Email delivery | EmailJS | End-to-end pipeline automation |

## 🚀 Quick Start (Local)

### Prerequisites
- Node.js v18 or higher
- An [Anthropic API key](https://console.anthropic.com)

### 1. Clone and install

```bash
git clone https://github.com/YOUR_USERNAME/homeadvisor-lx.git
cd homeadvisor-lx
npm install
```

### 2. Configure environment variables

```bash
cp .env.example .env
```

Edit `.env` and add your Claude API key:

```env
VITE_CLAUDE_API_KEY=sk-ant-your-key-here
```

### 3. Run locally

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)


## 🌐 Deploy to Vercel (Recommended)

### Option A — Vercel Dashboard (Easiest, ~5 minutes)

1. Push your code to GitHub
2. Go to [vercel.com](https://vercel.com) → **New Project**
3. Import your GitHub repository
4. In **Environment Variables**, add:
   - `VITE_CLAUDE_API_KEY`
   - `VITE_EMAILJS_SERVICE_ID`
   - `VITE_EMAILJS_TEMPLATE_ID`
   - `VITE_EMAILJS_PUBLIC_KEY`
5. Click **Deploy** — your app is live at `https://homeadvisor-lx.vercel.app`

### Option B — GitHub Pages

Update `vite.config.js`:

```js
export default defineConfig({
  plugins: [react()],
  base: '/homeadvisor-lx/',  // your repo name
})
```

Then deploy:

```bash
npm run deploy
```

App will be live at: `https://YOUR_USERNAME.github.io/homeadvisor-lx/`

### Option C — GitHub Actions (Auto-deploy on push)

1. Get your Vercel credentials:
   - `VERCEL_TOKEN` — from vercel.com/account/tokens
   - `VERCEL_ORG_ID` and `VERCEL_PROJECT_ID` — from `.vercel/project.json` after running `vercel link`

2. Add all secrets to **GitHub → Settings → Secrets and variables → Actions**:
   - `VERCEL_TOKEN`
   - `VERCEL_ORG_ID`
   - `VERCEL_PROJECT_ID`
   - `VITE_CLAUDE_API_KEY`
   - `VITE_EMAILJS_SERVICE_ID`
   - `VITE_EMAILJS_TEMPLATE_ID`
   - `VITE_EMAILJS_PUBLIC_KEY`

3. Push to `main` — deploys automatically.
